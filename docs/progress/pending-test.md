# 待测试

## 画布交互增强

+ [新增] 画布空白处右键菜单：「上传 / 从素材库选择 / 添加节点（二级菜单）/ 撤销 / 重做 / 粘贴」，撤销重做按历史状态置灰
+ [新增] 右键上传按模态自动建节点：图片 / 视频 / 音频 / 文本分别建对应节点，支持一次多选，多文件自动错位排布
+ [新增] 画布粘贴支持全类型：原生 paste 事件读取剪切板文件、图片、网页 `text/html` 的 `<img src>` 和纯文本，自动建立对应节点；Cmd+V 优先粘贴画布内部复制的节点，否则交给系统剪切板
+ [新增] 拖拽文件到画布同样走统一类型识别，支持多文件与文本文件
+ [优化] 连线浪涌动画：选中 / hover 关联 / 正在连线的连线叠加浅蓝色流动光带
+ [优化] 缩放跟手：滚轮 / 触控板捏合改为按帧合并提交，指数映射并归一化 `deltaMode`、锚定鼠标位置；缩放时不再重建节点回调与 `scale`，恢复 `React.memo` 命中；Safari 触控板捏合单独适配

+ [优化] 双击图片 / 视频节点改为把节点放大到接近铺满视口；全屏预览仍保留在节点悬浮工具条和右键菜单「放大预览」
+ [优化] 双指缩放灵敏度提高（`ZOOM_WHEEL_SENSITIVITY` 0.0022 → 0.005）
+ [新增] 节点右键菜单扩展：放大预览（全景为进入全景预览）、编辑文字 / 生成图片、截取首尾当前帧、保存到我的资产、下载、复制图片、上传替换、上传到云端、反转提示词、裁剪、分割、元素爆炸、框选修改、超分辨率、多角度、复制节点、创建副本、粘贴、删除

## 渠道协议

+ [新增] Flatkey 渠道协议：后台「协议」新增 Flatkey，接口地址填 `https://router.flatkey.ai/v1`，模型手输 `seedance-2.5` 即可；复用火山方舟的请求体格式（`content[]` + `ratio` + `duration`），接口走 Flatkey 标准的 `/v1/videos`（创建）与 `/v1/videos/{id}`（轮询）
+ [修复] Flatkey 任务接口地址：文档里的 `/v1/generation/tasks` 只对部分「通道类型」开放，seedance 系列会被上游拒绝（`this channel type is only available on /v1/videos and /v1/video/generations`），现改为标准 `/v1/videos`；误贴完整接口路径会自动裁剪，非视频接口（如 `/v1/images/generations`）保持原样透传
+ [修复] 视频错误提示误判：参数越界的正则用了裸 `ratio`，命中了 `gene(ratio)ns`，导致「通道不支持该接口」也被追加成「参数超出该模型允许范围」，现改为单词边界匹配

## 画布性能

+ [优化] 连线按视口裁剪：只渲染视口范围（外扩 240px）内的连线，视口外连线不再进入渲染树；复用已有相机状态与渲染帧，未新增订阅或 rAF，连线样式 / 箭头 / 选中态 / 流动动画与改动前一致
+ [优化] 拖拽节点时把分组落点检测并入同一渲染帧：原先每次 mousemove 会先同步提交吸附线与落点高亮、再由 rAF 提交节点位置（每帧 2~3 次渲染），现合并为每帧 1 次，高亮不再比节点位置慢一帧；分组归属规则与拖拽结果不变

## 图片缩略图

+ [新增] 图片缩略图：图片保存时用浏览器原生能力生成 WebP 缩略图（长边 512、质量 0.8）并随图片持久化，失败时静默回退、不影响保存
+ [优化] 画布图片节点、参考图条、素材选择弹窗、画布侧栏列表、生图历史页改用缩略图渲染；查看大图 / 下载 / 送入生成 / 编辑仍一律使用原图，画质与生成结果不变
+ [优化] 视频设置弹层的首尾帧与参考素材小图改用缩略图（36px 小图此前会加载整张原图）
+ [修复] 画布图片节点在高缩放下的清晰度：按显示设备像素（世界尺寸 × 画布缩放 × devicePixelRatio）判断，超过缩略图长边时自动改用原图，缩小时仍用缩略图

## Agent / MCP 接入

+ [新增] 画布侧边栏「Agent 接入」面板：按当前部署自动给出可复制的 MCP 注册命令（托管模式为当前站点同源 `/api/agent/mcp`，本地模式为可直接执行的仓库绝对路径命令，无需先 npm link），并支持在浏览器内直接填入地址与 token 连接本机 Agent
+ [修复] Agent 连接凭据改走 URL fragment（`#agent=<地址>&token=<token>`）并在读入后立即清除：不再进入 URL query、浏览器历史、Referer 与访问日志；query 形态凭据被完全忽略
+ [修复] 接入失败原因可区分并在面板内直接展示：缺少 token / 服务未启动 / token 失效 / 网络或跨域被拦 / 地址不是 Agent 服务，各带中文原因与下一步操作（此前只显示「连接失败」）
+ [修复] 直连模式意外断流会自动重连（退避 1→2→4→8→15 秒封顶，最多 6 次，连上后计数归零）；用户主动断开后绝不自动重连；任何时刻不会出现并发重复流
+ [修复] 直连连接失败后无法重试：此前建流失败未释放连接引用，导致第一次失败后再也连不上
+ [修复] 非对象 SSE 帧（如 `data: null`）不再产生未处理异常，畸形帧只丢弃该帧、不中断连接
+ [修复] 服务器托管模式开箱可用：`.env.example` 补齐 `AGENT_TOKEN` 与 `AGENT_PROXY_URL` 说明（app 与 agent 容器必须使用同一 token），缺失时后端启动打印明确告警（点明「`/api/agent/health` 可能正常但 `/events` 返回 401」这一典型现象）；compose 中 agent 端口改为只绑定 `127.0.0.1`
+ [修复] MCP 注册命令纠正：Codex 使用 `codex mcp add <名称> --url <地址>`（此前误写成 [CC] 的 `--transport http`，照抄会直接报错）
