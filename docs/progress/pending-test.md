# 待测试

## 画布交互增强

+ [新增] 画布空白处右键菜单：「上传 / 从素材库选择 / 添加节点（二级菜单）/ 撤销 / 重做 / 粘贴」，撤销重做按历史状态置灰
+ [新增] 右键上传按模态自动建节点：图片 / 视频 / 音频 / 文本分别建对应节点，支持一次多选，多文件自动错位排布
+ [新增] 画布粘贴支持全类型：原生 paste 事件读取剪切板文件、图片、网页 `text/html` 的 `<img src>` 和纯文本，自动建立对应节点；Cmd+V 优先粘贴画布内部复制的节点，否则交给系统剪切板
+ [新增] 拖拽文件到画布同样走统一类型识别，支持多文件与文本文件
+ [优化] 连线浪涌动画：选中 / hover 关联 / 正在连线的连线叠加浅蓝色流动光带
+ [优化] 缩放跟手：滚轮 / 触控板捏合改为按帧合并提交，指数映射并归一化 `deltaMode`、锚定鼠标位置；缩放时不再重建节点回调与 `scale`，恢复 `React.memo` 命中；Safari 触控板捏合单独适配

+ [优化] 双击图片 / 视频节点改为把节点放大到接近铺满视口；全屏预览仍保留在节点悬浮工具条和右键菜单「放大预览」
+ [优化] 双指缩放灵敏度提高（`ZOOM_WHEEL_SENSITIVITY` 0.0022 → 0.005）
+ [新增] 节点右键菜单扩展：放大预览（全景为进入全景预览）、编辑文字 / 生成图片、截取首尾当前帧、保存到我的资产、下载、复制图片、上传替换、上传到云端、反转提示词、裁剪、分割、元素爆炸、框选修改、超分辨率、多角度、复制节点、创建副本、粘贴、删除

## 渠道协议

+ [新增] Flatkey 渠道协议：后台「协议」新增 Flatkey，接口地址填 `https://router.flatkey.ai/v1`，模型手输 `seedance-2.5` 即可；复用火山方舟的请求体格式（`content[]` + `ratio` + `duration`），接口走 Flatkey 标准的 `/v1/videos`（创建）与 `/v1/videos/{id}`（轮询）
+ [修复] Flatkey 任务接口地址：文档里的 `/v1/generation/tasks` 只对部分「通道类型」开放，seedance 系列会被上游拒绝（`this channel type is only available on /v1/videos and /v1/video/generations`），现改为标准 `/v1/videos`；误贴完整接口路径会自动裁剪，非视频接口（如 `/v1/images/generations`）保持原样透传
+ [修复] 视频错误提示误判：参数越界的正则用了裸 `ratio`，命中了 `gene(ratio)ns`，导致「通道不支持该接口」也被追加成「参数超出该模型允许范围」，现改为单词边界匹配
